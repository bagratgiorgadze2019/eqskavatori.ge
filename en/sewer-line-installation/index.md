# Sewer line installation

A sewer pipe needs the right slope and depth, or it will block. We dig the trench, lay the pipe and connect it to the septic tank or the existing system.

## What's included

- Trench digging with a mini excavator
- Laying sewer pipes at the right slope
- Connecting to the septic tank or existing system
- Backfilling the trench

## When you need it

- Sewer for a new house
- A line from the house to the septic tank
- Replacing an old, damaged pipe
- Sewer for a village house

## Slope matters

- Without enough slope, waste settles and the pipe blocks. We check the slope on site.

## In villages

- Where there's no network, we run the line to a septic tank and can install the tank too.
